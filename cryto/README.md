# Crypto Forecast Models

ชุดโมเดล crypto ใช้ schema log เดียวกับ Forex เพื่อให้ frontend อ่านได้เหมือนกัน

## Run

```powershell
python .\cryto\models_\run_all_models.py
```

## Outputs

- `cryto/logs/crypto_models_summary.csv`
- `cryto/logs/crypto_models_human_log.md`
- `cryto/logs/btcusd_forecast_latest.json`
- `cryto/logs/ethusd_forecast_latest.json`
- `cryto/logs/solusd_forecast_latest.json`
- `cryto/logs/bnbusd_forecast_latest.json`
- `cryto/logs/xrpusd_forecast_latest.json`
