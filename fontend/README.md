# Forex Log Dashboard

Next.js frontend สำหรับแสดงผล log จากโมเดลใน `../ai_chatbot/logs`

## Run

```powershell
npm install
npm run dev
```

เปิด `http://localhost:3000`

## Data Source

- `../ai_chatbot/logs/forex_models_summary.csv`
- `../ai_chatbot/logs/forex_models_human_log.md`
- `../ai_chatbot/logs/*_forecast_latest.json`
